# Mesh PKI is istio-csr issuing from a persistent SSM-backed CA

Istio's built-in CA is replaced by istio-csr issuing from a cert-manager CA whose key is generated by Terragrunt and stored in AWS SSM. One CA then covers mesh mTLS, survives cluster rebuilds and allows cross-cluster trust, at a small fraction of AWS Private CA's cost; ephemeral per-rebuild CAs were rejected as complexity without benefit.
