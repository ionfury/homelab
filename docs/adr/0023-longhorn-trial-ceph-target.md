# Longhorn is a trial; Ceph is the long-term storage target

Longhorn is the current block and RWX storage layer, adopted to give it a real trial; the brief Rook-Ceph deployment in 2025 was removed for that reason, not because Ceph was rejected. The long-term home for bulk storage, including the media library, is Ceph, so Longhorn-specific restructuring such as sharding the media library is not pursued.
